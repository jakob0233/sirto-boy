# RAPDROP

Moderne statische Demo-Website für Deutschrap-Releases.

## Enthalten
- Live-Countdown zum nächsten Release
- Release-Grid mit Status „Kommt bald“ / „Draussen“
- Filter für heute, diese Woche, nächste Woche und bereits erschienene Releases
- Suche nach Artist oder Song
- Wochenkalender
- Artist-Hub
- Responsive Dark-UI
- Spotify-Suchlinks
- Datenstruktur im JavaScript für spätere API-/Datenbank-Anbindung

## Wichtig
Die aktuell eingebauten Releases sind ausdrücklich **Demo-Daten** und keine verifizierten aktuellen Releaseangaben.

Für die echte Version sollte die Datenliste in `index.html` durch eine verlässliche Release-Quelle/API ersetzt werden.
